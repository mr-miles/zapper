# Examples

Configs to run as they are, each in a directory with a README that walks through it.

| Example | Shows |
|---|---|
| [mini-firm](mini-firm/README.md) | The Office at its smallest: a CEO who contracts a writer for a task from the board, both Claude Code |
| [shopping-list](shopping-list/README.md) | A company that grows to fit its task: the CEO hires a product manager to write a spec, then engineers to build a Node and React app from it in the firm's git repository |
| [github-firm](github-firm/README.md) | The shopping list company on GitHub: a repository of yours, reached through your GitHub App with a token per worker that the VMs never see; pull requests whose checks the engineers watch with `gh`, merged by you |
| [research-firm](research-firm/README.md) | Research as a firm: a research manager scopes a question with web search and writes a plan, researchers ask for its sites and each write a pack of cited Markdown documents, the manager collates them into one, and the CEO can then commission a prototype engineer to build from it |
